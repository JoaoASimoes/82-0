# 82-0 · Perfect Season 🏀

Draft five NBA players and try for a perfect 82-0 season. Works on phones and desktop; on a phone you can add it to the home screen and it opens like an app (PWA). Available in European Portuguese and English.

**Play:** https://joaoasimoes.github.io/82-0/

## How it plays

1. A **team** and a **decade** are drawn. Pick one player from that roster for your starting five (2 guards, 2 forwards, 1 center).
2. You only see each player's **per-game averages** for that team and decade (points, rebounds, assists, steals, blocks), sortable by any stat.
3. You get **one team re-roll** and **one decade re-roll** per game. A player can move to any position he played during his career.
4. The season has no luck: 82 fixed opponents, and you win a game if your five is stronger. Two identical fives always get the same record.

Each player has a hidden 0–99 rating for his impact on that team in that decade. It decides the season but is never shown in the game.

## Player data

`src/data/players.json` is generated by `scripts/build_players.py` from the [NBA Stats (1947-present)](https://www.kaggle.com/datasets/sumitrodatta/nba-aba-baa-stats) Kaggle dataset (Basketball-Reference data). For each franchise and decade since the 1980s it keeps the 10 players with the biggest total contribution, their per-game averages, and the hidden rating, which blends:

- **impact** (47%): minutes-weighted BPM, scaled by minutes per game;
- **production** (15%): how far his per-game stats stood above that season's league;
- **prestige** (38%): MVP and DPOY votes, All-NBA/All-Defense teams, All-Star picks and titles with that team.

To regenerate it, download the dataset into `data_raw/` (git-ignored) and run:

```bash
python3 -m venv .venv
.venv/bin/pip install -r scripts/requirements.txt
.venv/bin/python scripts/build_players.py
```

## Development

Requires [Node.js](https://nodejs.org) 22.

```bash
npm install
npm run dev     # dev server (also reachable from a phone on the same Wi-Fi)
npm run check   # typecheck + tests
npm run build   # production build in dist/
```

Every push to `main` is tested and deployed to GitHub Pages.
